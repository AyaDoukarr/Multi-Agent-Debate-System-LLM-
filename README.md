## Technique de raisonnement

Ce projet utilise une architecture multi-agents avec raisonnement avancé.

### ReAct
Chaque agent suit un processus :
1. Analyse du sujet
2. Production d’arguments
3. Observation de la réponse adverse
4. Réponse

### Self-Correction
Le modérateur critique les arguments et produit une synthèse équilibrée.
